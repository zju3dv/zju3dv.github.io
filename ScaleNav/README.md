# ScaleNav project website

Public project page for **ScaleNav: Scalable Internet Video Pretraining for Language-Conditioned Local Navigation**.

The Paper, Code, Model, and Data buttons link to arXiv and the public GitHub and Hugging Face repositories.

Open `index.html` through a static HTTP server. There is no build step and no package installation. Edit `index.html`, `style.css`, `app.js`, and `assets/demos.json` as needed.

This directory contains the project website and its media, served at https://zju3dv.github.io/ScaleNav/. Changes merged into the repository’s `master` branch deploy through its existing GitHub Pages configuration.

Font licenses are included in `assets/fonts/`.
